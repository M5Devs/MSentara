# MSentara format parsers

Importers that translate on-disk formats into the plain data structures
declared in `src/core` (`Model`, `MeshData`, `Skeleton`, `AnimationClip`).
They never touch the GPU, the window, or the UI, so they are unit-testable
without a display.

## Implemented

- **`PmxLoader.{hpp,cpp}`** — PMX 2.0/2.1 model parser (geometry, materials,
  skeleton, deform weights). Produces `ms::Model`.
- **`VmdLoader.{hpp,cpp}`** — VMD (Vocaloid Motion Data) parser. Produces
  `ms::AnimationClip` (bone tracks + morph scalar tracks), converting MMD's
  left-handed space into the right-handed space PMX loading produces.
- **`ShiftJis.{hpp,cpp}`** + **`SjisTable.hpp`** — a self-contained CP932 →
  UTF-8 decoder for VMD's fixed-width Shift-JIS bone names. The table is
  generated by `scripts/gen_sjis_table.py`; there is no ICU/iconv dependency,
  so it works on Desktop, Web, and Android alike.

Binary layouts are easy to get subtly wrong. **Read `docs/REFERENCES.md`
before changing any parser** — it lists the authoritative PMX/VMD sources and
the layout facts that have already caused bugs here.
